# Draft answers for the NeurIPS 2024 paper checklist

**Status: DRAFT, not the submission.** The brief says the official checklist is a `.tex`
file on Moodle, appended after the references and filled in. That file has not been
supplied to this repository, so `neurips_2024_ethics_checklist.tex` is still an explicit
placeholder. These are draft answers for the standard NeurIPS 2024 checklist topics, written
from what this project actually did, so that filling in the real file takes minutes.

How to use: when you have the Moodle file, copy each `[Yes]/[No]/[NA]` and justification
into the matching question. Check the wording of every question against the real file
(this list is from the standard NeurIPS 2024 checklist, and the course may have edited it).
Where a justification below says CONFIRM, it depends on something only the author(s) know or
on the final numbers in the report. Change any answer that is not true for what you submit.
